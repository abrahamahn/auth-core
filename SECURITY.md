# Security policy

## Supported versions

Until the first stable release, only the latest `0.x` release receives security updates.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use the repository's private GitHub
security advisory flow and include the affected API, reproduction, impact, and any proposed fix.

## Scope

This library provides deterministic authentication decisions. Applications remain responsible for
secure cryptography, secret handling, transport security, persistence, rate limiting, provider
configuration, and authorization enforcement.
